# Amenity Reservations

A [Chickadee Bandit](https://chickadeebandit.com/app-library/amenity-reservations) app.

Reserve shared facilities — pool, clubhouse, courts, BBQ. Board configures amenities, booking windows, usage limits, and approval requirements.

## Features

- Amenities configured by the board.
- Booking windows and per-household usage limits.
- Optional approval requirement.
- Residents reserve and see availability.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-amenity-reservations/releases/latest/download/bundle.json
```
